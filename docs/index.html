Capabilities

Everything you need for email-centric investigations

Built with a defensive mindset, mailforen focuses on high-signal, publicly accessible data. Every action is logged with timestamps to preserve investigative context.

Email Forensics

Parse raw .eml files, reconstruct the Received hop path, extract originating IPs, and inspect authentication results.

  • Header chain reconstruction
  • SPF, DKIM, DMARC & MX checks
  • Phishing triage focused analysis

Infrastructure Intel

Map DNS, hosting context, and historical certificate data to uncover related assets and pivot points.

  • Domain DNS (A/AAAA/MX/NS/TXT/CNAME)
  • IP reverse DNS & enrichment
  • Certificate Transparency via crt.sh

Pivoting & Tracing

Safely follow redirects, extract file metadata, and generate passive username pivots across common platforms.

  • Safe URL redirect tracing
  • EXIF & file metadata extraction
  • Passive username correlation

Case-Centric Workflow

Keep every lookup tied to an investigation. Findings, inputs, results, risk levels, and timestamps are stored in a local SQLite database for clean handoffs and repeatability.

  • mailforen case new/list/show
  • Attach any module output to a case with --case-id
  • Fully local by default – no cloud telemetry

Evidence-Ready Reporting

Generate clean, shareable reports in the format your workflow demands. Designed for tickets, case notes, and SIEM ingestion.

  • Markdown – ideal for Git/notes
  • HTML – clean, human-readable
  • JSON – structured for automation/SIEM
  • PDF – formal documentation (graceful fallback if tooling missing)
Quick Start

From suspicious email to actionable report in minutes

Install locally, create a case, run your checks, and generate a consolidated report.

setup.sh
➜ git clone https://github.com/fajardoclark359-alt/mailforen.git
➜ cd mailforen && pip install -e .
➜ mailforen version
mailforen v0.1.0 | For authorized use only
➜ mailforen case new "Incident-001" --target phishing.example.org
➜ mailforen email headers ./suspicious.eml --case-id 1
➜ mailforen domain intel phishing.example.org --case-id 1
➜ mailforen report generate --case-id 1 --format markdown
✓ Report saved to ~/.mailforen/reports/
