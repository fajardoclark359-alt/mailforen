Capabilities

Everything you need for email-centric investigations

Built with a defensive mindset. High-signal, publicly accessible data. Every lookup logged with timestamps for investigative context.

Email Forensics

Parse raw .eml files, reconstruct the Received hop path, extract originating IPs, and inspect authentication results.

  • Header chain reconstruction
  • SPF, DKIM, DMARC & MX checks
  • Typo-squat & disposable detection
  • From/Reply-To/Return-Path mismatch

Domain Intelligence

Map DNS, hosting context, and historical certificate data to uncover related assets and pivot points.

  • MX, A, AAAA, NS, TXT, CNAME via DoH
  • SPF all-qualifier & DMARC policy
  • DNSSEC validation (DNSKEY)
  • Certificate Transparency (crt.sh)

URL & Redirect Tracing

Safely follow redirects, extract file metadata, and generate passive username pivots across common platforms.

  • Punycode / homoglyph detection
  • IP-literal hosts & URL shorteners
  • Suspicious TLDs & credentials in URL
  • HEAD→GET redirect chain tracing

Raw Message Analysis

Deep inspection of full email messages including headers, body, and embedded artifacts.

  • Received hop ordering & timestamps
  • Authentication-Results parsing
  • Date anomaly detection
  • Embedded URL extraction & scoring
  • Message-ID domain alignment
  • .eml / .msg file upload support

Evidence-Ready Output

Generate clean, shareable reports in the format your workflow demands. Designed for tickets, case notes, and SIEM ingestion.

  • Markdown — ideal for Git/notes
  • HTML — clean, human-readable
  • JSON — structured for automation
  • PDF — formal documentation
